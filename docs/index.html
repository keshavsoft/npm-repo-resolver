Why We Built This

Before downloading gigabytes of source code or auditing packages, you first need a reliable, verified Source of Truth: What authentic Git repositories power this library and every single one of its recursive dependencies?

npm-repo-resolver solves this in pure, zero-Git isolation:

  • Zero Disk Clones: Inspects manifests and graphs without touching your local workspace or executing untrusted lifecycle scripts.
  • Transitive Graph Resolution: Employs @npmcli/arborist in an ephemeral sandbox to map the full transitive tree.
  • Git Provenance Normalization: Standardizes diverse URLs (git+https, SCP, SSH) into canonical HTTPS Git remotes.
  • Smart Owner Fallback: Automatically infers missing Git URLs for internal/monorepo packages that omit repository metadata.

The 3-Act Story Engine

Act 1: The Gatekeeper

Validates the package specification, parses scoped names (@org/pkg), and determines root identity and owner context.

Act 2: The Cartographer

Recursively traverses the dependency tree using @npmcli/arborist in an ephemeral tmp workspace with 100% cleanup.

Act 3: The Detective

Canonicalizes repository remotes, detects monorepo parent owners, deduplicates peers, and produces the final Source of Truth manifest.

Usage & Output Formats

# 1. Output clean JSON stream (stdout)
npx npm-repo-resolver express

# 2. Pretty-print formatted JSON
npx npm-repo-resolver json-renderers --pretty

# 3. Print formatted console summary table
npx npm-repo-resolver express --table

# 4. Count unique repositories
npx npm-repo-resolver react --count

Composable UNIX Pipelines

Because status updates are directed to stderr, standard output is pure JSON. You can pipe directly into jq or into our sibling cloner: 

# Pipe directly into git-sibling-cloner to download all sources
npx npm-repo-resolver express | npx git-sibling-cloner ./sources

# Extract all clone URLs with jq
npx npm-repo-resolver express | jq -r '.[].cloneUrl'
